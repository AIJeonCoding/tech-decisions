| **내 프로젝트** | **@Version + 멱등키 4중 + Pessimistic IT** | **카카오페이 철학에 가까움** |

## 면접 예상 Q&A

**Q. 빅테크 글을 어떻게 모았나요?**
> Claude Code로 한국 빅테크 블로그 글을 직접 fetch + 분석해서 인용을 추출했습니다. 자동화 인덱싱(LLM + 임베딩) 코드는 V2로 준비해뒀고, V1은 검증된 시드 데이터로 동작합니다.

**Q. 내 프로젝트 신뢰도가 95%인 근거는?**
> evidence URL이 GitHub 리포로 가고, ADR/CHANGELOG/RUNBOOK이 모두 코드에 함께 존재합니다. 면접관이 직접 검증 가능. 빅테크는 공개 글에서 인용을 추출했지만 글 내용을 그대로 인용한 게 아니라 의역한 부분도 있어 신뢰도 0.85~0.93입니다.

**Q. V2에서 RAG 챗봇은 언제?**
> 인프라(Postgres + pgvector + Anthropic API)가 켜지면 즉시 동작합니다. 코드는 `crawler/`에 다 있고, V1 시드 위에 LLM 자동 추출본이 덮어쓰는 구조로 설계했습니다.

**Q. settlement-msa 개발에서 가장 어려웠던 부분은?**
> 회계 항등식 자동 검증. 처음엔 단순 이중기장으로 충분하다 생각했는데, 시산표 합계가 안 맞는 회귀가 한 번 있고 나서 ValidateTrialBalanceStep + ValidateBalanceSheetStep 두 단계로 자동 가드를 만들었습니다 (ADR-0030). 이게 우아한의 외부 PG 대사보다 한 단계 안쪽 — 내부 원장 정합성을 시스템화한 거고, 회계 자격증 학습 컨텍스트가 결정적이었습니다.
