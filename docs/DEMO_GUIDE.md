# 데모 가이드

면접 때 화면 공유로 보여줄 시연 시나리오. 각 시나리오는 **30~60초** 안에 끝나도록.

## 4개 V1 도메인 — 도메인별 미니 데모

각 도메인의 비교 페이지에서 보여줄 셀 1~2개와 한 줄 멘트를 정리.

### 시나리오 1 — 결제·정산 비교 (메인 데모)

**URL**: `/compare/payment-settlement`

**흐름**:
1. 메인페이지 → 결제·정산 카드 클릭
2. **"토스 / 동시성 제어" 셀 클릭** → 사이드 패널: *Redis Global Lock + JPA @Lock 이중 보호* + 코어뱅킹 MSA 전환기 원문 (2023-08-31)
3. 같은 줄 **"카카오페이 / 동시성 제어"** 클릭 → *putIfAbsent + Redis/Local 이중 캐시, TPS 170→400* (2023-12-07)
4. 같은 줄 **"우아한형제들 / 동시성 제어"** 클릭 → *Transactional Outbox + 5분 자동 재발행* (2022-04-12)

**한 줄 멘트**:
> "결제 동시성 한 축에서만 토스는 분산락+JPA로, 카카오페이는 캐시 동시성 정책으로, 우아한형제들은 Outbox로 풀었습니다. 같은 문제, 다른 답을 한 페이지에서 비교합니다."

### 시나리오 2 — MSA 전환

**URL**: `/compare/msa-migration`

**흐름**:
1. 카카오페이 / 분산 트랜잭션 셀 → *멱등성 API + ActResult 함수형* (2022-05-25)
2. 우아한형제들 / 분산 트랜잭션 셀 → *RDBMS Outbox + 5분 자동 재발행 배치* (2022-04-12)
3. 토스 / 안전한 마이그레이션 셀 → *실시간 검증 + 배치 검증 + E2E + 순차 배포* (2023-08-31)

**한 줄 멘트**:
> "분산 트랜잭션 처리만 봐도 함수형 ActResult, RDBMS Outbox, Saga 보상 등 회사마다 다른 답을 골랐습니다. 어느 게 정답이 아니라 자기 도메인에 맞는 패턴 선택이 핵심입니다."

### 시나리오 3 — 실시간 데이터 파이프라인

**URL**: `/compare/realtime-data`

**흐름**:
1. 우아한형제들 / CDC 셀 → *Debezium MySQL source connector + 토픽별 outbox 분리* (2024-05-30)
2. 카카오페이 / 메시지 브로커 셀 → *RabbitMQ → Kafka 재설계, 처리 8배* (2024-12-10)
3. 쿠팡 / 스트림 처리 셀 → *Kafka + Flink 분 단위 노출* (2024-06-25)

**한 줄 멘트**:
> "같은 Kafka를 써도 Debezium CDC, RabbitMQ에서 마이그레이션, Flink 집계 등 풀이가 모두 다릅니다."

### 시나리오 4 — 검색

**URL**: `/compare/search`

**흐름**:
1. 우아한형제들 / 검색 엔진 셀 → *keyword 타입 변경 + 자체 분석기, P99.9 20% 개선* (2024-11-28)
2. 쿠팡 / 색인 파이프라인 셀 → *product-query 키 비정규화 + ground truth 통합* (2020-05-07)
3. 당근 / 검색 엔진 셀 → *ECK 자동화로 배포 5시간 → 30분* (2023-05-09)

### 시나리오 5 — 추천

**URL**: `/compare/recommendation`

**흐름**:
1. 당근 / 후보 생성 셀 → 벡터 ANN + 위치 기반 필터
2. 쿠팡 / 재정렬 셀 → Multi-task DNN + 비즈니스 KPI 가중
3. 우아한형제들 / 후보 생성 셀 → 시간대·날씨 컨텍스트 시그널

## 검색 도구 데모

**URL**: `/search`

**흐름**:
1. `Outbox` 검색 → 우아한형제들 카프카 글이 1위 (FTS5 BM25)
2. `정산` 검색 → 토스 정산 개편기 + 라이더 정산 + 셀러 정산
3. `BM25` 검색 → 네이버 D2 + 우아한형제들 검색 글

**한 줄 멘트**:
> "외부 ES 없이 SQLite FTS5만으로 한국어 prefix 검색까지 동작합니다. 운영비 0."

## 어드민 콘솔 데모

**URL**: `/admin/cells`

**흐름**:
1. 페이지 진입 → 통계 박스 3개 (전체/고신뢰/검증)
2. 도메인별 평균 신뢰도 막대 그래프 → 결제·정산이 가장 높음
3. 테이블에서 신뢰도 색상 배지 (녹색/노랑/빨강) 보여주며 검증 상태 시연
4. 첫 evidence URL 클릭 → 원문 즉시 이동

**한 줄 멘트**:
> "셀마다 사람 검증 상태와 신뢰도가 노출됩니다. V2에서 LLM 자동 추출이 들어와도 사람이 운영 콘솔에서 검수하고 승격하는 구조."
